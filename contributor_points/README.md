# Contributor points

Contributors get points for new icons and updates. They can spend points to increase icon request priority on the Lawnicons dashboard.

[Lawnicons dashboard](https://lawnicons-requests.vercel.app/)

## Example

`contributor_points/nickname.txt`

```text
balance 0
earned 25
spent 25

awards
+5 pr 1234 +1 icon
+20 pr 1240 +4 updates

spends
app.lawnchair.lawnicons/app.lawnchair.lawnicons.MainActivity 5
app.lawnchair/app.lawnchair.LawnchairLauncher 10

fulfilled
com.github.android/com.github.android.main.MainActivity 10
```
